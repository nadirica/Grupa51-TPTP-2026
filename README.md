# Turistički vodič Tuzlanskog kantona

## Ovaj projekat predstavlja interaktivni digitalni vodič osmišljen da olakša istraživanje Tuzlanskog kantona kako domaćim tako i stranim turistima. Cilj je na jednom mjestu objediniti sve prirodne ljepote, historijske spomenike i moderne atrakcije ove regije.
